# Карта переиспользования

Источник рядом с репозиторием, не внутри него: `medical-assistant3 Р optima` (Doctor Opus, Next.js 14). Production-репозиторий не изменялся и не подключён импортом. Общей базы, бакетов и секретов нет.

| Модуль | Путь | Решение | Почему |
| --- | --- | --- | --- |
| Анонимизация текста | `lib/anonymization.ts` | ADAPT, не копировать как есть | Функция снимает все даты. ATLAXIS обязан сохранить дату исследования и убрать дату рождения, телефон, почту, документ, адрес. |
| DICOM | `lib/dicom-processor.ts` `anonymizeDicomBuffer` | DO NOT USE как достаточное обезличивание | Затираются только теги. Проверки текста, впечатанного в изображение, нет. Такой файл не идёт в разбор. |
| PDF | `lib/pdf-parser.ts` | DO NOT USE | Заглушка, текст не извлекает. |
| Приём файлов в браузере | `lib/file-extractor.ts` | REBUILD на сервере | Завязан на браузерный `File`. Серверный приём, карантин и хэш написаны отдельно. |
| Лабораторный разбор | `lib/lab-parser.ts` | DO NOT USE | Считает тренды по уже готовым заключениям модели. Здесь факты читаются из текста правилами. |
| Консилиум | `lib/diagnostics/orchestrator.ts` `runConsilium` | DO NOT USE в этой поставке | Зовёт модели и собирает клиническое заключение. Справочный разбор пока считается правилами, без вызова модели. |
| Двухфазный протокол | `lib/protocol-stage2.ts` | DO NOT USE | Проверяет текст врачебной заметки, а не снимок. Измерения с изображения не выдумываются. |
| Протоколы | `lib/protocols.ts` | DO NOT USE | Это сценарии действий, не версионированный каталог рекомендаций для справки. |
| Смартфон | `lib/mobile-bridge-store.ts` | ADAPT | Ссылка с кодом отправляет файлы в тот же разбор. Очередь Doctor Opus с адресами анализа и общими data URL не копируется. Отдельного пункта меню нет. |
| База пациентов | `lib/patient-db.ts`, `lib/database.ts` | DO NOT USE | Чужое хранилище и чужие пациенты. У ATLAXIS свой локальный каталог `data/`, в git не входит. |
| Разговор | MCP Doctor Opus | PREPARE | В Doctor Opus своего MCP нет. В ATLAXIS подготовлен локальный сервер `mcp/doctor-opus/server.ts`: вопрос принимается и наружу не отправляется. |
