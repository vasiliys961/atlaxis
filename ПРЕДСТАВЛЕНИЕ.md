# ATLAXIS

Личный справочный разбор уже загруженных документов. Человек приносит бланки, выписки и снимки. Сервис собирает их в один лист: что написано, как это менялось, где записи не сходятся и чего в комплекте нет.

Сайт: https://atlaxis-tan.vercel.app

Диагноз не ставится. Лечение не назначается. Дозы, которых нет в документе, не появляются. Пробел называется пробелом, а не заданием сдать анализ.

На экране два входа: **Документы** и **Разбор**.

---

## Что умеет

**Принять файлы.** Текст, CSV, Markdown, PDF с текстовым слоем, Word `.docx`, PNG, JPEG, WEBP и DICOM. Старый `.doc` нужно сохранить как `.docx`. Снимок с iPhone в HEIC сохраняется как JPEG. С компьютера и со смартфона по QR-коду. Загрузка сразу отпускает человека: чтение идёт следом. Пока файл ждёт, подпись «Проверяется». Когда его читают — «Разбирается». Потом «Готово», «сохранён отдельно» или «Не удалось разобрать».

**Спрятать лишнее в тексте.** Даты исследований остаются. Телефон, почта, документ, адрес и имя из текста уходят до разбора.

**Собрать один лист по нескольким файлам.** Числа, единицы и даты берутся из строк документа. Рядом остаётся исходная строка. Нажатие на запись открывает файл и место в нём.

**Поставить записи по времени.** Шкала идёт по дате документа. Строка без даты стоит в конце. Если показатель повторяется, видно, вырос он, снизился или не изменился. Разные дозы в разные годы — смена записи во времени. Две разные дозы в один день или в одном документе — расхождение. Связь «в тот же период» не называется причиной.

**Показать пробел.** Если нужного показателя в комплекте нет, это сказано прямо. Вопрос врачу остаётся вопросом.

**Прочитать снимок.** PNG, JPEG и WEBP при наличии ключа читаются. Снимок HEIC с iPhone сначала становится JPEG, затем читается так же. В разбор попадают только строки, которые совпали со словарём показателей. Сырой ответ модели на лист не выводится. Если снимок прочитан и в том же месяце есть бланк, они стоят рядом. Нового числа от этого не появляется.

**Сопоставить с каталогом.** Человек выбирает Россию, Европу или США. Если российской записи в каталоге нет, разбор ищет опубликованную. Нашёл — цитата стоит в листе как поиск, не как запись каталога. Не нашёл — разбор так и пишет. Европейские и американские записи при этом остаются, с пометкой, что они не заменяют российскую рекомендацию. Число цели, если оно есть в записи, показано как цель источника для названной группы, не как личная цель. Название модели на лист не выводится.

**Пояснить уже собранное.** Окно «Профессор» отвечает по готовому разбору. У каждой находки кнопка «Профессору»: расхождение, строка по времени, смена показателя, пробел и вопрос на приём уходят в это окно по одной. В начале листа кнопка **Весь разбор профессору** отправляет комплект целиком и просит пояснить, как его читать вместе. Профессор поясняет, что уже записано. Диагноза нет. Спокойный вопрос и спокойную тему пишет одна модель. Спорную запись, дозу и срочность берёт другая. Если вопрос сам по себе неясен, его сначала коротко классифицируют. Просьбу отменить препарат и текст про срочные симптомы закрывает готовая фраза, без модели.

**Удалить данные.** Одно действие стирает документы, разбор и оригиналы этого человека. Чужой набор по ссылке не открывается.

## Как пользоваться

Сайт открывается по адресу https://atlaxis-tan.vercel.app. В шапке два раздела: **Документы** и **Разбор**. Знак ATLAXIS слева возвращает на «Документы». Справа на этих двух экранах открыто окно **Профессор**.

Путь такой. Сначала положить свои файлы. Дождаться подписи «Готово». Открыть «Разбор» и прочитать лист сверху вниз. Нажать строку, если нужно увидеть, откуда она взята. У находки нажать **Профессору**: она уйдёт в окно справа, и её можно обсудить. Чтобы спросить, как читать весь лист вместе, нажать **Весь разбор профессору**. На приём взять вопросы из листа, а не схему из чата.

### Документы

Здесь человек собирает комплект и выбирает, какие рекомендации смотреть.

| Кнопка или место | Что даёт |
| --- | --- |
| **Загрузить документы** | Прокручивает к полю загрузки |
| Поле «Перетащите сюда» и **Выбрать файлы** | Принимает текст, CSV, Markdown, PDF, Word `.docx`, PNG, JPEG, WEBP, HEIC с iPhone и DICOM, до 20 МБ. Можно сразу несколько |
| **Инструкция** | Короткое окно «Как пользоваться». Закрывается кнопкой **Понятно** |
| **Готовый PNG или JPEG** | Берёт снимок, который уже лежит на компьютере. HEIC тоже принимается и сохраняется как JPEG |
| **Со смартфона** | Показывает QR-код на два часа. **Закрыть** убирает окно, файлы остаются в списке |
| Строка файла | Имя, дата, сколько измерений нашлось и подпись состояния |
| Карточка **Разбор собран** | Появляется, когда хотя бы один файл прочитан. Ведёт в текст разбора |
| **Россия**, **Европа**, **США** | Меняет, какие рекомендации ищет лист. Для России сначала ищется опубликованная российская. Личные числа от этого не меняются |
| **Удалить мои данные** | Спрашивает ещё раз. **Да, удалить всё** стирает документы, разбор и оригиналы. **Оставить** ничего не трогает |

Подписи на файле читаются так. **Проверяется** — файл принят и ждёт. **Разбирается** — его читают. **Готово** — строки вошли в лист. **Снимок сохранён отдельно**, **PDF сохранён отдельно** и **Word сохранён отдельно** — файл лежит в комплекте, но его числа в разбор не попали. **Не удалось разобрать** — чтение не вышло, лист по остальным файлам всё равно собирается.

### Разбор

Один лист. Пока файлов нет, на экране кнопка **К документам**. Когда файлы есть, разделы идут сверху вниз. Пустой раздел не показывается.

| Раздел | Что даёт |
| --- | --- |
| Заголовок | Коротко, что нашлось в комплекте. Кнопка **Очистить** стирает файлы, лист и переписку. Она же есть, пока лист ещё собирается |
| **Файлы** | Какие файлы вошли и в каком они состоянии |
| **Где записи не сходятся** | Две разные записи об одном и том же. Нажатие открывает файл и строку |
| **По времени** | Все найденные строки по дате документа. Без даты — в конце. Связи здесь не называются |
| **Как менялось** | Повтор одного показателя: вырос, снизился или остался. Смена дозы в разные даты — смена записи, не назначение |
| **Что написано в документах** | Темы комплекта и короткий пересказ. Если данных мало, это сказано в начале темы. Имя модели здесь не пишется |
| **Чего в комплекте нет** | Пробел. Это не задание сдать анализ |
| **Что видно вместе** | Записи одного месяца рядом. Причина не называется |
| **Что сказать нельзя** | Где разбор останавливается: диагноза и лечения здесь нет |
| **Что взять на приём** | Вопросы врачу по расхождениям и пробелам |
| **Какие рекомендации смотрели** | Внизу листа. Для России сначала блок **Что нашлось в опубликованных рекомендациях**: найденная российская рекомендация или фраза, что поиск её не нашёл. Затем записи каталога: организация, название, версия, год. Ссылка **Источник** открывает запись каталога. Для Европы и США этот блок стоит после каталога |
| Подвал | Дата сборки и версия обработки |

### Профессор

Окно справа. Оно поясняет уже собранный лист. Кнопка **Профессору** у находки отправляет одну строку. Кнопка **Весь разбор профессору** в начале листа отправляет комплект: как его читать вместе. Дальше это можно обсуждать ходом переписки. Ответ держится того, что уже есть в документах. Диагноз не ставится, лечение не назначается.

| Кнопка | Что даёт |
| --- | --- |
| **Профессору** | Стоит у находки на листе. Отправляет одну строку в это окно и открывает переписку |
| **Весь разбор профессору** | Стоит в начале листа. Просит пояснить комплект целиком: что записано, как менялось, где записи не сходятся и чего нет |
| **Очистить чат** | Стирает переписку в окне. Файлы и лист остаются |
| **Свернуть** | Прячет переписку, окно остаётся полоской |
| **Открыть** | Возвращает переписку |
| Поле вопроса | Сюда пишется следующий вопрос по уже отправленной находке. Пример в поле: «что видно по холестерину?» |
| **Спросить** | Отправляет вопрос. Пока ответ пишется, кнопка ждёт |

Обычный вопрос про число и его ход отвечает коротко. Вопрос про дозу, расхождение или срочность разбирается внимательнее. Просьба отменить препарат и текст про неотложные симптомы закрываются готовой фразой: к модели они не уходят.

### Со смартфона

Эта страница в меню не стоит. На неё попадают только по QR-коду с компьютера, где уже открыт разбор.

| Кнопка | Что даёт |
| --- | --- |
| **Снять снимок** | Камера телефона. Файл уходит в тот же комплект. HEIC с iPhone сохраняется как JPEG |
| **Готовый PNG или JPEG** | Снимок из галереи телефона. HEIC тоже принимается и сохраняется как JPEG |

После отправки имя файла появляется на компьютере в списке «Документов».

### Как применить для себя

1. Собрать комплект за несколько лет: бланки, выписки, снимки. Чем больше дат, тем виднее ход показателя.
2. Дождаться «Готово» на своих файлах.
3. Выбрать страну рекомендаций до чтения каталога. Для России разбор ищет опубликованную рекомендацию. Если не находит, лист так и пишет и оставляет европейские и американские с пометкой.
4. Прочитать «По времени» и «Как менялось». Это картина своих записей, не вывод о болезни.
5. Открыть «Где записи не сходятся» и нажать источник. На приём имеет смысл нести именно эти две строки, а не пересказ.
6. Выписать вопросы из «Что взять на приём». Это список для разговора с врачом. Он не заменяет приём.
7. Пробелы из «Чего в комплекте нет» оставить вопросами. Сами по себе они не говорят, какой анализ сдавать.
8. У находки, которая смущает, нажать **Профессору** и обсудить её текст. Чтобы спросить, как читать все анализы вместе, нажать **Весь разбор профессору** в начале листа. Ответ остаётся пояснением. Решение о дозе остаётся у врача.
9. Новый бланк кладётся в тот же комплект. Лист пересобирается, шкала времени удлиняется.
10. Если комплект больше не нужен, **Удалить мои данные** стирает его целиком. Восстановить после этого нельзя.

## Что отложено

Это решено не делать в текущей поставке.

- Отдельная база. Сейчас файлы и состояние лежат в закрытом хранилище. Базу запишем и прилепим потом.
- Разбор кадра DICOM. Такой файл принимается и в измерения не читается.
- Перевод страниц.
- Оплата.
- Кабинет врача.
- FHIR.

Класс доказательности отдельно не ищем. Его пишем только если он уже есть в хранимой записи. В текущих карточках по холестерину его нет.

## Что можно прилепить

Это не новая очередь. Каждая вещь садится на уже собранный разбор.

- **База под тем же владельцем.** Разбор, факты и файлы остаются как есть. Меняется только место, где они лежат.
- **Российская запись каталога.** Sonar уже ищет опубликованную и показывает цитату. Отдельная строка каталога появится, когда будет настоящий источник: организация, название, версия, год и ссылка. До этого европейские и американские остаются с пометкой.
- **Класс доказательности в карточке.** Одна строка, и только если этот класс написан в источнике.
- **Чтение DICOM.** Имеет смысл, когда появится проверка текста, впечатанного в кадр. До этой проверки файл по-прежнему лежит отдельно.
- **Новые темы каталога.** Добавляются данными, без переписки экранов. Официальный перечень из пятнадцати кластеров и двадцати осей сам собой не появляется.
- **Внешний разбор снимка.** Для него уже есть пустой интерфейс. Вызов, оплата и чужой код туда не переносятся.
- **История сборок.** Каждая сборка разбора уже сохраняется. На экран выведена последняя: дата и версия обработки. Список прежних сборок можно показать позже, отдельным экраном его не делать.

## Перспектива

Это следующий круг. Он садится на тот же разбор: что написано в файле, как это менялось, где пробел. Заключение о болезни и схема лечения по-прежнему не появляются.

**Генетические файлы и VCF.** Человек приносит файл вариантов. Разбор читает, что в нём записано: вариант, место, как это названо в файле. Рядом остаётся источник. Консультация генетика — это чтение этого списка человеком, который имеет на это право. Окно может пояснить уже извлечённые строки. Оно не объявляет диагноз и не назначает действие.

**Разбор DICOM.** Кадр исследования входит в тот же лист, что бланки и обычные снимки. Сначала проверяется текст, впечатанный в изображение. Пока проверки нет, файл только хранится. Когда проверка есть, в разбор попадают видимые измерения и подписи, со ссылкой на кадр. Находка, которой нет на изображении, не добавляется.

**Doctor Opus по MCP.** Это внешний поставщик, не код внутри ATLAXIS. Ему уходит задание на снимок, обратно приходят находки с источником. Так чтение изображений становится точнее, чем один проход глаз. В чате те же находки можно собрать консилиумом: несколько коротких шагов по уже извлечённому, затем один текст для человека. Консилиум поясняет записи. Он не ставит диагноз и не подбирает лечение. Оплата и ключи Doctor Opus остаются снаружи.

**Сравнение изображений.** Два исследования одного человека стоят по дате, как повторные анализы. Видно, что на более позднем снимке записано иначе. Причину и диагноз разбор не называет.

**Доступ.** Сейчас набор открыт только владельцу. Дальше человек сам называет, кого пустить и на какой срок. Ссылка не публичная, файл по ней не раздаётся. Отдельного кабинета врача из этого не получается.

**Много языков.** Меняется язык экрана и пояснения. Числа, единицы, названия препаратов и названия рекомендаций остаются как в источнике. Их не переводит свободный словарь.

**Клинические рекомендации.** Сейчас Sonar ищет опубликованную российскую и, если не находит, оставляет США и Европу с пометкой. Дальше в каталог можно положить саму запись: организация, название, версия, год и ссылка. Сначала российская, когда такой источник будет в хранилище. Старая версия не называется текущей. Класс доказательности пишется, только когда он есть в этой записи. Рекомендация поясняет уже загруженные данные. Она не становится планом лечения.

## Технические параметры

Граница продукта — в `TZ.md`. Что сделано и что отложено — в `TZ-сводка.md`. Что взято из Doctor Opus и что не копируется — в `docs/DOCTOR_OPUS_REUSE_MAP.md`.

### Модели

Ключ только на сервере. Локально это `POLZA_AI_API_KEY`. На Vercel демонстрация идёт через `OPENROUTER_API_KEY`, потому что Польза оттуда не отвечает. Если заданы оба, берётся OpenRouter. Фронтенд к провайдеру не обращается. Без ключа разбор собирается правилами.

| Задача | Модель |
| --- | --- |
| Снимок в JSON | Gemini 3.8 Flash, `google/gemini-3.8-flash` |
| Спокойная тема и обычный вопрос | Sonnet 5.5, `anthropic/claude-sonnet-5.5` |
| Спорная запись, доза, срочность | Opus 5.5, `anthropic/claude-opus-5.5` |
| Непонятный вопрос в чате | Luna, `openai/gpt-6-luna` |
| Поиск опубликованных рекомендаций по уже записанным анализам. Для России сначала российские | Sonar, `perplexity/sonar` |

В факты со снимка попадают только строки словаря. Число, доза или назначение, которых нет в документах, в текст не попадает.

### Стек

| Слой | Что стоит |
| --- | --- |
| Приложение | Next.js 14, App Router, React 18 |
| Язык | TypeScript, строгий режим |
| Проверка входа | Zod |
| Текст из PDF | unpdf, только текстовый слой |
| Текст из Word | mammoth, только `.docx` |
| Снимок iPhone | HEIC переводится в JPEG до чтения |
| Разбор | Правила в `lib/`: анонимизация, словарь, отчёт, проверка текста |

| Хранение | Закрытый Vercel Blob, если задан `BLOB_READ_WRITE_TOKEN`. Иначе каталог `data/{владелец}/` |
| Владелец | Cookie `atlaxis_owner`. Чужой идентификатор отвечает 404 |
| Тесты | Node test runner через `tsx` |
| Стили | Свой CSS в `app/globals.css` |

Нужен Node.js 18.17 или новее.

Сборка:

```bash
npm run build
npm start
```

В `.env.local` можно задать `POLZA_AI_API_KEY`. На Vercel для моделей задаётся `OPENROUTER_API_KEY`. Для постоянного хранилища нужен `BLOB_READ_WRITE_TOKEN`. Оригинал файла по ссылке не отдаётся.

### Файлы

Принимаются `.txt`, `.csv`, `.md`, `.pdf`, `.docx`, `.png`, `.jpg`, `.jpeg`, `.webp`, `.heic`, `.heif`, `.dcm`, до 20 МБ.

Текст, PDF с текстовым слоем и Word `.docx` разбираются словарём. Старый `.doc` нужно сохранить как `.docx`. Если в Word или PDF нет текста, файл сохраняется отдельно и в числа не входит. PNG, JPEG и WEBP при наличии ключа читает Gemini; в разбор входят только узнанные строки. Снимок с iPhone в HEIC перед чтением сохраняется как JPEG. DICOM принимается и в измерения не читается: отдельного разбора кадра нет.

Кнопка «Со смартфона» показывает QR-код на два часа. Страница телефона в меню не стоит. «Удалить мои данные» стирает документы, разбор и оригиналы этого владельца.

### Проверка

```bash
npm test
npx tsc --noEmit
```

`npm test` гоняет разбор текста, PDF, Word, HEIC, дозы, динамику и синтетические случаи из `fixtures/cases/`.
