# ATLAXIS

Справочный разбор загруженных медицинских документов. Сервис собирает факты, динамику, расхождения и пробелы. Диагноз и лечение не назначает.

Граница продукта и объём поставки — в `TZ.md`. Карта того, что взято из Doctor Opus и что сознательно не копируется — в `docs/DOCTOR_OPUS_REUSE_MAP.md`.

## Стек

| Слой | Что стоит |
| --- | --- |
| Приложение | Next.js 14, App Router, React 18 |
| Язык | TypeScript, строгий режим |
| Проверка входа | Zod |
| Текст из PDF | unpdf, только текстовый слой |
| Разбор | Правила в `lib/`: анонимизация, словарь показателей, оси, рекомендации, отчёт |
| Хранение | Каталог `data/{владелец}/` на диске: `state.json` и оригиналы `{id}.bin` |
| Владелец | Cookie `atlaxis_owner` и заголовок `x-atlaxis-owner`. Чужой `:id` отвечает 404 |
| Тесты | Node test runner через `tsx` |
| Стили | Свой CSS в `app/globals.css` |

Этого в поставке нет: PostgreSQL, объектное хранилище, очередь, кабинет врача, FHIR, публичные ссылки на файлы. Фронтенд к провайдеру модели не обращается.

Модели идут через Пользу AI, ключ только на сервере: `POLZA_AI_API_KEY`. Снимок читает Gemini 3.8 Flash (`google/gemini-3.8-flash`) и пишет JSON видимого текста. По этому JSON и разбору текст пишут Opus 5.5 (`anthropic/claude-opus-5.5`) и GPT-6.1 (`openai/gpt-6.1-sol`). Число, доза или назначение, которых нет в документах, в пересказ не попадает. Без ключа разбор собирается правилами.

Нужен Node.js 18.17 или новее.

## Запуск

```bash
npm install
npm run dev
```

Открыть `http://localhost:3000`.

Если порт 3000 занят:

```bash
npx next dev -p 3210
```

На macOS при ошибке «too many open files»:

```bash
ulimit -n 65536
WATCHPACK_POLLING=true npx next dev -p 3210
```

Сборка и запуск собранной версии:

```bash
npm run build
npm start
```

Переменных окружения нет. Секреты и ключи моделей не требуются.

## Как пользоваться

В меню два пункта.

1. **Документы.** Загрузить файлы или нажать «Открыть пример: бланки и PDF». Выбрать страну рекомендаций: Россия, Европа или США. Для России в каталоге этой поставки нет цитируемой рекомендации, целевые цифры в разбор не подставляются.
2. **Разбор.** Один лист: файлы, расхождения, динамика, темы, что видно вместе, чего сказать нельзя, вопросы на приём, какие рекомендации смотрели. Источник строки открывается через «Откуда это».

Кнопка «Инструкция» открывает окно с тем, как пользоваться сервисом.

Готовый снимок добавляется кнопкой «PNG или JPEG». Кнопка «Со смартфона» показывает QR-код: на телефоне можно снять изображение или выбрать готовый PNG или JPEG, и файл попадёт в тот же разбор. Код действует два часа. Страница телефона в меню не стоит.

Принимаются `.txt`, `.csv`, `.md`, `.pdf`, `.png`, `.jpg`, `.jpeg`, `.webp`, `.dcm`, до 20 МБ. Текст и PDF с текстовым слоем разбираются. Картинки и DICOM сохраняются, но в измерения не входят: вшитый в снимок текст не проверяется. PDF без текстового слоя тоже остаётся вне разбора.

«Удалить мои данные» стирает каталог владельца целиком. Каталог `data/` в git не попадает.

Форма проверки качества открывается ссылкой внизу разбора (`/review`) и в меню не стоит. Общая оценка вроде «в целом нормально» не сохраняется: нужны цитата, почему это неверно и как должно звучать.

## Проверка

```bash
npm test
npx tsc --noEmit
```

`npm test` гоняет разбор текста, PDF, дозы, динамику и синтетические случаи из `fixtures/cases/`.
