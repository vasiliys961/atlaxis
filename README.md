# ATLAXIS

Справочный разбор уже загруженных медицинских документов. Сервис показывает, что написано, как это менялось, где записи не сходятся и каких данных в комплекте нет. Диагноз и лечение не назначает.

Сайт: https://atlaxis-tan.vercel.app

Граница продукта — в `TZ.md`. Что сделано и что отложено — в `TZ-сводка.md`. Карта того, что взято из Doctor Opus и что не копируется — в `docs/DOCTOR_OPUS_REUSE_MAP.md`.

## Что видит человек

В меню два пункта: **Документы** и **Разбор**.

На «Документах» загружают бланки, выписки и снимки, выбирают страну рекомендаций и могут удалить свои данные. Пока файл ждёт чтения, подпись «Проверяется». Когда чтение идёт — «Разбирается». Дальше «Готово» или «Не удалось разобрать».

«Разбор» — один лист. Сверху файлы, расхождения, записи по дате документа, динамика и темы. Дальше пробелы, что видно в один период и вопросы на приём. Рекомендации стоят внизу. Нажатие на строку открывает источник: файл и место в нём. Строка без даты стоит в конце шкалы. Препарат в тексте остаётся цитатой, не схемой приёма. У находки кнопка «Профессору»: её текст уходит в окно справа.

Если российской записи в каталоге нет, разбор ищет опубликованную. Нашёл — цитата стоит в листе как поиск, не как запись каталога. Не нашёл — разбор так и пишет. Европейские и американские записи при этом остаются, с пометкой. Число цели, если оно есть в записи, показано как цель источника для названной группы, не как личная цель. Класс доказательности пишется только когда он уже есть в записи. Названия моделей и сырой JSON снимка на лист не выводятся.

Окно «Профессор» объясняет уже собранные сведения. Обычный вопрос отвечает коротко. Вопрос про дозу, расхождение или срочность разбирается внимательнее. Просьба сменить лечение и текст про срочные симптомы закрываются готовой фразой.

## Модели

Ключ только на сервере. Локально это `POLZA_AI_API_KEY`. На Vercel Польза не отвечает, поэтому демонстрация идёт через `OPENROUTER_API_KEY`. Если заданы оба, берётся OpenRouter. Фронтенд к провайдеру не обращается. Без ключа разбор собирается правилами.

| Задача | Модель |
| --- | --- |
| Снимок в JSON | Gemini 3.8 Flash, `google/gemini-3.8-flash` |
| Спокойная тема и обычный вопрос | Sonnet 5.5, `anthropic/claude-sonnet-5.5` |
| Спорная запись, доза, срочность | Opus 5.5, `anthropic/claude-opus-5.5` |
| Непонятный вопрос в чате | Luna, `openai/gpt-6-luna` |
| Поиск опубликованных рекомендаций по уже записанным анализам. Для России сначала российские | Sonar, `perplexity/sonar` |

В факты со снимка попадают только строки словаря. Число, доза или назначение, которых нет в документах, в текст не попадает.

## Стек

| Слой | Что стоит |
| --- | --- |
| Приложение | Next.js 14, App Router, React 18 |
| Язык | TypeScript, строгий режим |
| Проверка входа | Zod |
| Текст из PDF | unpdf, только текстовый слой |
| Текст из Word | mammoth, только `.docx` |
| Снимок iPhone | HEIC переводится в JPEG до чтения |
| Разбор | Правила в `lib/`: анонимизация, словарь, отчёт, проверка текста |
| Очередь | Загрузка сразу отвечает, чтение идёт отдельно |
| Хранение | Закрытый Vercel Blob, если задан `BLOB_READ_WRITE_TOKEN`. Иначе каталог `data/{владелец}/` |
| Владелец | Cookie `atlaxis_owner`. Чужой идентификатор отвечает 404 |
| Тесты | Node test runner через `tsx` |
| Стили | Свой CSS в `app/globals.css` |

Нужен Node.js 18.17 или новее.

## Запуск

```bash
npm install
npm run dev
```

Открыть `http://localhost:3000`.

Если порт 3000 занят:

```bash
npx next dev -p 3210
```

На macOS при ошибке «too many open files»:

```bash
ulimit -n 65536
WATCHPACK_POLLING=true npx next dev -p 3210
```

Сборка:

```bash
npm run build
npm start
```

В `.env.local` можно задать `POLZA_AI_API_KEY`. На Vercel для моделей задаётся `OPENROUTER_API_KEY`. Для постоянного хранилища нужен `BLOB_READ_WRITE_TOKEN`. Оригинал файла по ссылке не отдаётся.

## Файлы

Принимаются `.txt`, `.csv`, `.md`, `.pdf`, `.docx`, `.png`, `.jpg`, `.jpeg`, `.webp`, `.heic`, `.heif`, `.dcm`, до 20 МБ.

Текст, PDF с текстовым слоем и Word `.docx` разбираются словарём. Старый `.doc` нужно сохранить как `.docx`. Если в Word или PDF нет текста, файл сохраняется отдельно и в числа не входит. PNG, JPEG и WEBP при наличии ключа читает Gemini; в разбор входят только узнанные строки. Снимок с iPhone в HEIC перед чтением сохраняется как JPEG. DICOM принимается и в измерения не читается: отдельного разбора кадра нет.

Кнопка «Со смартфона» показывает QR-код на два часа. Страница телефона в меню не стоит. «Удалить мои данные» стирает документы, разбор и оригиналы этого владельца.
